ЧЕГО НЕТ И ПОЧЕМУ
  data/req.sh  — в нём была сессия Instagram, убран из соображений
                 безопасности. Нужно взять свежий cURL (см. ниже).
  venv/        — привязан к пути, создаётся заново.

УСТАНОВКА (по одной команде за раз)

1. Распакуйте архив, папку ig-tag-parser положите куда удобно.
   Дальше в командах подставляйте свой путь вместо ПУТЬ.

2. cd ПУТЬ/ig-tag-parser
3. python3 -m venv venv
4. source venv/bin/activate
5. pip install -r requirements.txt
6. which python
   Должен показать путь с ig-tag-parser/venv

7. Проверьте, что данные на месте:
   ls data/tags | wc -l
   Ожидается 115

ВЗЯТЬ СЕССИЮ INSTAGRAM

8. В Chrome откройте instagram.com/explore/search/keyword/?q=%23маникюр
9. F12 - вкладка Network - Clear - в поле Filter впишите graphql
10. Проскроллите ленту вниз до догрузки постов
11. Правый клик на запросе с самым большим Size - Copy - Copy as cURL (bash)
12. Сразу в терминал, ничего больше не копируя:
    pbpaste > data/req.sh
13. wc -c data/req.sh
    Ожидается около 5000. Если 100-200 — буфер затёрся, повторите с шага 9.

ЗАПУСК СБОРА

14. RETRY_UNFINISHED=1 python src/run_tags.py data/tags.txt

Собранные теги пропускаются, продолжится с недобранных.
Осталось около 17 тегов, примерно 3-4 часа.

ЕСЛИ ОШИБКА 1357004
Протухли токены. Ctrl+C, затем шаги 9-13, затем шаг 14.

ВЫГРУЗКА В EXCEL
  python src/export_xlsx.py
Файл появится в data/exports/

ВАЖНО
Не переносите папку проекта после создания venv — venv хранит
абсолютные пути и сломается. Если перенесли: rm -rf venv и шаги 3-5.
