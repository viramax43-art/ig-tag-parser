СБОРЩИК АККАУНТОВ INSTAGRAM ПО ТЕГАМ

══════════════════════════════════════
WINDOWS — ПРОГРАММА С ОКНЕШКОМ (exe)
══════════════════════════════════════

  1) Соберите один раз:  build_exe.bat
  2) Запуск:  dist\IGTagParser\IGTagParser.exe

В окне три вкладки для правок + «Запуск»:
  Теги        → data/tags.txt
  Аккаунты    → data/accounts.txt
  Прокси      → proxies.txt
  Запуск      → старт / стоп / Excel / вставка req.sh

Файлы data\ и proxies.txt лежат РЯДОМ с exe — их можно
править и в блокноте. Не переносите только exe без папки.

══════════════════════════════════════
MAC — КНОПКИ .command (как раньше)
══════════════════════════════════════

Четыре файла с цифрами в начале имени — это кнопки.
Открывайте их двойным кликом по порядку.

  1 Настройка.command        один раз при установке
  2 Обновить сессию.command  когда сбор скажет, что сессия недействительна
  3 Запустить сбор.command   основная работа
  4 Выгрузить в Excel.command получить файл с результатом

ЕСЛИ MACOS НЕ ДАЁТ ОТКРЫТЬ
Первый раз система спросит разрешение. Нажмите на файле
правой кнопкой -> Открыть -> в окне снова Открыть.

ЧТО ВНУТРИ
  data/tags.txt       список тегов для сбора
  data/accounts.txt   рабочие аккаунты (см. ниже) — тогда сбор в потоках
  proxies.txt         прокси для dump-формата аккаунтов
  data/tags/          собранные данные, НЕ УДАЛЯТЬ
  data/exports/       готовые файлы Excel
  data/sessions/      кэш логинов (создаётся сам)
  src/                код

МУЛЬТИАККАУНТ (РЕКОМЕНДУЕТСЯ)
Скопируйте data/accounts.txt.example → data/accounts.txt.
Одна строка = один поток (свой Instagram + свой IP):

  username;password;2fa_secret;ip:port:proxyuser:proxypass

2fa_secret — ключ из приложения-аутентификатора (не шестизначный код).
Шаблон GraphQL один раз положите в data/req.sh
(в exe — кнопка «Вставить req.sh»).
Дальше логин и прокси берутся из accounts.txt автоматически.

Если accounts.txt пуст — работает старый режим с одной сессией в req.sh.

СКОЛЬКО ИДЁТ СБОР
Один тег — от минуты до часа, зависит от его размера.
Весь список — около суток. С несколькими аккаунтами быстрее
пропорционально числу строк. Прогресс сохраняется постоянно,
можно закрывать и продолжать позже: уже собранные
теги пропускаются автоматически.

ВАЖНО
Не переносите и не переименовывайте папку с программой после
настройки. Ноутбук не должен уходить в сон во время сбора.
